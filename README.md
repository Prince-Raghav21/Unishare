# Student Resource Exchange

A simple website where students can upload and find study material (notes, assignments, past papers and lab sheets) for their courses, such as MTH165, CSE111, PHY175, CSE326 and CHE110.

## Features
- Upload a file with a course, type, title and short description
- Add your own course code if it is not in the list
- Search, sort and filter by course tab and resource type
- View PDFs, images and text files inside the page
- Two-click delete so files are not removed by accident
- Responsive layout that works on phones

## Technologies
- HTML for the page structure
- CSS for the cyan and white design (variables, flexbox, grid, media query)
- JavaScript for the logic (arrays, DOM, events, localStorage, IndexedDB)
- pdf.js (loaded from cdnjs) to show PDF pages

## How to run
Open `index.html` in any modern browser. No installation is needed.

To publish it online: go to the repository **Settings > Pages**, choose the `main` branch and the root folder, and save.

## Limitation
Uploaded files and added courses are saved only in the browser of the device being used, so other students cannot see them. A future version could add a backend and database to share files between users.
